# AgriConnect: High-Fidelity UI Design System & Ergonomic Specification

## 1. Design System Tokens (Rural Accessibility Calibrated)

### Color Palette (High-Contrast WCAG AAA Compliance)
* **Primary Green (#1B5E20)**: Rural trust, agricultural prosperity, primary actionable CTAs.
* **Warm Sunlight Amber (#E65100)**: ROI calculations, high-value opportunities, pending alerts.
* **Emergency Crimson (#C62828)**: Pest/mold SOS alerts, urgent heatwave warnings.
* **Crisp Neutral Light (#F9FBE7)**: Background canvas reducing harsh outdoor glare in direct sunlight.
* **Surface Slate (#263238)**: High-contrast text color ensuring maximum readability for cataract/older eyes.

### Typography & Dialect Hierarchy
* **Primary Font**: Noto Sans Devanagari (for Hindi and Malvi scripts).
* **Secondary Numeric Font**: Inter (bold, tabular numerals for currency figures).
* **Type Scale**:
  * Large Screen Titles: 24sp Bold
  * Action Button Labels: 18sp Semi-Bold
  * Body & Voice Subtitles: 16sp Regular
  * Secondary Metadata: 14sp Regular (Minimum font size across the entire application).

### Rural Physical Ergonomics
* **Minimum Touch Target**: 56px x 56px across all buttons and clickable cards to accommodate calloused/dusty thumbs.
* **Spacing Grid**: Strict 8-point baseline grid (8px, 16px, 24px, 32px).
* **Haptic Touch Confirmation**: 40ms light vibration upon button press to confirm user action.
* **Audio-First Autoplay**: Automatic vernacular audio narration triggers on screen mount.
